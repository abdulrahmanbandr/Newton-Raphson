# Newton-Raphson Method for Finding Roots of Nonlinear Equations

This project implements the Newton-Raphson method, which is a
powerful numerical technique used to approximate the root of a nonlinear
equation.
The program allows the user to input:
A function f(x)
Its derivative f'(x)
An initial guess. 
The method then iteratively applies the Newton-Raphson formula Until it
converges to a solution within a small error tolerance.
Additionally, the function is visualized using maplotlib to show the curve
and the location of the estimated root.
This project demonstrates both the mathematical logic and the practical
implementation of a classic root-finding algorithm.
